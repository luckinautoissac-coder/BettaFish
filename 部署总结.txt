========================================
   ⚠️ 重要提醒
========================================

❌ BettaFish 不适合部署到 Vercel！

原因:
  • Vercel 是 Serverless 平台
  • 不支持长期运行的进程
  • 不支持 WebSocket
  • 不支持多个子进程
  • 函数执行时间限制 60 秒

✅ 推荐部署平台:

1. Railway (推荐) ⭐⭐⭐⭐⭐
   - 最适合 Python 长进程应用
   - $5/月 免费额度
   - 配置最简单
   - 网址: https://railway.app/

2. Render (免费) ⭐⭐⭐⭐
   - 完全免费
   - 15 分钟无活动会休眠
   - 网址: https://render.com/

3. 自己的 VPS ⭐⭐⭐⭐⭐
   - 完全控制
   - 使用 Docker 部署
   - 成本: $5-10/月

【推荐】Railway 部署 (15 分钟)

1. 注册: https://railway.app/

2. 创建项目:
   - New Project
   - Deploy from GitHub repo
   - 选择 BettaFish 仓库

3. 配置环境变量:
   - 打开你本地的 .env 文件
   - 复制全部内容

5. 访问你的应用:
   https://你的应用.railway.app


【免费】Render 部署 (15 分钟)

1. 注册: https://render.com/
   - 使用 GitHub 登录

2. 创建 Web Service:
   - New + → Web Service
   - 连接 GitHub
   - 选择 BettaFish 仓库

3. 配置环境变量:
   - 复制 .env 文件内容
   - 添加到 Render Environment

4. 创建服务 (10 分钟)

5. 访问你的应用:
   https://你的应用.onrender.com

⚠️ 注意: Render 免费版会在 15 分钟不活动后休眠

========================================
   ❓ 常见问题
========================================

Q: 为什么不能用 Vercel？
A: Vercel 是 Serverless 平台，不支持 BettaFish 
   需要的长进程、WebSocket 等特性。会失去 
   80% 的功能。

Q: Railway 和 Render 选哪个？
A: 
   • Railway: 稳定，不休眠，$5/月
   • Render: 免费，但会休眠

Q: 部署失败怎么办？
A: 
   1. 查看部署日志
   2. 确认环境变量是否配置完整
   3. 查看 故障排查完成.md
   4. GitHub Issues 求助

Q: .env 文件被推送了怎么办？
A: 
   git rm --cached .env
   git commit -m "chore: 移除敏感文件"
   git push

   然后立即修改 API Keys！

Q: 可以同时部署到多个平台吗？
A: 可以！Railway（生产）+ Render（测试）
